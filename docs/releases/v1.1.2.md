# V3 Blaze Firmware v1.1.2

## Full Mod UI fixes

- Fixed incomplete shutdown-screen coverage when opened from Now Playing.
- Fixed header and top-spacing issues on pages opened from the Now Playing menu.
- Fixed theme-color changes returning to Music → Songs instead of the main screen.
- Fixed Settings card corruption when the scrollbar disappeared after scrolling.

Stock + LDAC Fix is unchanged.

## Known limitations

The album-art screensaver may take about 1.5 seconds to update after a track change; the same behavior occurs on official TempoTec v1.2 and v1.3.

Bluetooth reception can become unstable with sustained high-bitrate LDAC or poor RF conditions. AAC has been more reliable in testing. This is separate from the v1.3 Bluetooth Receiver LDAC audio corruption corrected by the project; the RF cause is still unknown.

Select the desired firmware and rename it to `v3_analog_2025.upt` for microSD installation.
